Comparación de direcciones

A — Señal protagonista: prioriza el impacto visual y las tareas urgentes.

B — Control operativo: facilita la supervisión y organización de tareas para administradores.

C — Checklist primero: prioriza la ejecución de actividades y la experiencia móvil del estudiante.

Las tres propuestas son exploratorias. La dirección definitiva será seleccionada después de evaluar su claridad, eficacia, coherencia con el Brandboard y utilidad para los usuarios de Interact2Hack Staff.
